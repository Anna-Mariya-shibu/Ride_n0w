 RideNow - Vehicle Rental System

RideNow is a simple web-based vehicle rental system. It allows users to view vehicles and book them for daily, weekly or monthly rentals.

 Features

- View available vehicles
- Search and filter vehicles
- Book two-wheelers and four-wheelers
- Select rental dates
- Daily, weekly and monthly rental plans
- View booking history
- Agency dashboard to add vehicles
- Admin dashboard to view vehicles and bookings

 Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

 How to Run

1. Open the project in VS Code.
2. Open `index.html` in a browser.
3. Use the navigation bar to access the different pages.
